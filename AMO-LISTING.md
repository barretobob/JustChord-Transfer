## Português (Brasil)

### Nome
JustChord Transfer

### Resumo
Transfere cifras do Cifra Club e Banana Cifras diretamente para o JustChords no macOS.

### Descrição
JustChord Transfer adiciona cifras do Cifra Club e Banana Cifras diretamente à biblioteca do JustChords no macOS.

Recursos:
- Importação direta para a biblioteca do JustChords.
- Reconhecimento de tom, capo e tablaturas.
- Detecção de músicas duplicadas.
- Opções para Substituir, Manter atual ou Duplicar.
- Backup automático da biblioteca antes de cada alteração.
- Integração local com o JustChord Transfer Helper por Native Messaging.

Requisitos:
- Firefox Desktop.
- macOS.
- JustChords.
- JustChord Transfer Helper instalado no Mac.

Baixe o Helper para macOS:
https://github.com/barretobob/JustChord-Transfer/releases/latest

Privacidade:
O conteúdo da cifra é enviado somente do Firefox para o Helper local. O projeto não envia cifras, biblioteca ou dados pessoais para servidores próprios ou serviços de terceiros.

## English

### Name
JustChord Transfer

### Summary
Transfers chord sheets from Cifra Club and Banana Cifras directly to JustChords on macOS.

### Description
JustChord Transfer adds chord sheets from Cifra Club and Banana Cifras directly to the JustChords library on macOS.

Features:
- Direct import into the JustChords library.
- Key, capo, and tablature handling.
- Duplicate song detection.
- Replace, Keep current, or Duplicate options.
- Automatic library backup before every change.
- Local integration with the JustChord Transfer Helper through Native Messaging.

Requirements:
- Firefox Desktop.
- macOS.
- JustChords.
- JustChord Transfer Helper installed on the Mac.

Download the macOS Helper:
https://github.com/barretobob/JustChord-Transfer/releases/latest

Privacy:
Chord-sheet content is sent only from Firefox to the local Helper. The project does not send chord sheets, library data, or personal data to its own servers or third-party services.

Code, documentation, and support:
https://github.com/barretobob/JustChord-Transfer
